# Sakinah — Daily Reminders • Correct Mosque Icon Edition

This package uses **one single approved image** for every icon: the glossy ivory-and-gold miniature mosque from your last approved design. Every file below has been regenerated from the same original image, **including `favicon.ico`**, which had accidentally contained the older Qur’an artwork.

## What to upload

1. Unzip this package.
2. Open your separate Sakinah GitHub repository (NOT the closet or cinema repository).
3. Choose **Add file → Upload files** and select all website files at once, keeping them **in the repository root** alongside `index.html`.
4. Commit changes, confirming replacement of older icon files if prompted.
5. Make sure GitHub Pages is using **main / (root)**.
6. On iPhone, remove the *old Home Screen shortcut only*, reopen the newly published Sakinah site in Safari, and use **Share → Add to Home Screen** again. You can also clear the browser cache for a stale bookmark icon.

## Contents

- `index.html` — Sakinah website with your existing adhan, Islamic trackers and daily reminder settings.
- `apple-touch-icon.png` — iPhone/iPad icon, 180 × 180.
- `favicon.ico` — browser icon with several embedded resolutions, all the mosque.
- `favicon-16.png` and `favicon-32.png` — browser PNG favicons.
- `icon-192.png` and `icon-512.png` — PWA/Android icons.
- `site.webmanifest` — site icon metadata.
- `app-icon-preview.png` and `icon-preview.png` — previews of the same mosque art.

### Limitations

Real notifications when the app is closed still require a working push-delivery backend. In-app reminders can function while Sakinah is open. The existing data-safety and cloud saving behavior is unchanged.
